## Essential formula you should be able to explain

\[
r_{t,h}=\ln(C_{t+h}/C_t),\qquad h\in\{5m,1h\}.
\]

Illustrative example: If reference close at decision time is 100000 USD and the **future** next 5m reference close later turns out to be 100100 USD, then log return is about **0.0009995**. The future value is available only for training labels **after time passes**. It cannot be used by the forecasting features at time t. This is NOT net trade profit.
